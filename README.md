## 怎样使用

1. 先根据队伍最弱孩子的体力选线，再确认开放、天气、票务和交通。
2. 路线介绍、活动日期、票价和天气快照分别看待；旧资料不会自动变成当期有效信息。
3. “控制步行3—4公里”是队伍组织目标，不代表已经测量全线；未知爬升如实标注。
4. 不进入未开放、封控区域；不因路线带有“亲子”“入门”标签而忽略陡坡和撤返。
5. 本仓库不保存儿童姓名、实际身高、家庭住址、证件、联系方式、实时轨迹等私人记录。
