# 本轮更新与验收

- 主题：北京赏红叶与银杏；8-9岁亲子小队；山林徒步优先，排除城市公园，不为凑数扩为十条。
- 输出：7个独立一日方案、六维评分及总分排序；戒台寺轻松备选；定都阁、广慧寺各自条件研究。
- 资料：本轮及前续步骤实际读过9篇小红书原帖正文（千灵山两篇，其余西山、北宫、百望山、古道、红螺寺、潭柘寺、广慧寺各一篇）；各自链接、作者与采用内容见方案。搜索结果、转载和未切换成功的帖子未记为已读正文。
- 年份：千灵山有2025原帖；其余以2025官方秋季资料对照，未声称每处都已读到2025小红书原帖。2026实况、春季稳定线路、旧营业说明分开使用。
- 补查定都阁与广慧寺：直接读区文旅局公告、两步路2025实走、Beijing Hikers 2026实走相册、旅游平台当季推荐、近期小红书与评论。保留“公告取消AAA不等于闭园”“近期游客报修缮”“发布日期不等于拍摄日期”的区别。
- 图片：只收明确CC许可实景并署名，不把未授权小红书原图或AI风景放入仓库。历史照片不证明今年叶色。
- 路线：七份SVG为节点示意，两份条件研究用Mermaid；没有伪造GPS、方位、实测距离或爬升。
- 分享文件：9页PDF（总览1页、七方案各1页、补查1页）；1200像素宽精简长图。由同一JSON数据生成，评分和排序一致。
- 验收：复算七份总分、PDF逐页渲染检查、照片完整解码、本地链接、私人字段和会话令牌检查。餐馆未电话核营业、未订餐买票、未实地踩线，未知事项保留。

生成方式：运行 `docs/生成赏秋资料.py`，依赖ReportLab与Pillow；当前字体路径为macOS Arial Unicode。更换运行环境时先替换中文字体路径。
