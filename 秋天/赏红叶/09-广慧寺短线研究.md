# 广慧寺：短往返保留，完整环穿不默认给孩子

2026-10-26补查。地点为**潭柘寺镇桑峪村**，不是斋堂镇同名村。条件方案，不进TOP 7确定排名。

## 多渠道交叉结论

- [2026-10-18北京旅游网](https://www.visitbeijing.com.cn/article/4TeunGHpU29)推荐广慧寺、万桑古道、古银杏及桑峪村林荫小院咖啡，证明方向值得看，但没有儿童短线轨迹和全线开放承诺。
- 实际读到[木末辛夷小红书原帖](https://www.xiaohongshu.com/explore/6adb6887000000002a0124a1)，2026-10-25编辑：**7公里、爬升500米、成人2.5-3小时**，有短陡坡，定都阁修缮不开放。评论说明照片拍于“上周末”，不当作发布当天的银杏实况。作者说轻松，不等于孩子团也轻松。
- [2023北京旅游网万桑段](https://www.visitbeijing.com.cn/article/4C8m2DiLUuQ)记录约8公里、爬升400米、无厕所补给。不同起点支线不能平均成一条核准路线。
- [Beijing Hikers 2026-03-07实走相册](https://www.beijinghikers.com/photos-and-news/through-the-hills-to-dingdu-pavilion-and-tanzhe-temple-2026-03-07/)可交叉确认山径、铺装路、公路混合线路，春季团走不证明秋季全线通行。

## 可研究的路线

桑峪村合法停车点 → 确认开放的正规上山步道 → 广慧寺古树区 → 原路返回同一停车点。

示意不按比例，不作GPS导航。朋友须给近期同线轨迹、总长、爬升、破损、陡坡与撤返点。本队选线偏好约5公里内、爬升尽量约300米内，不是儿童统一能力上限。未取得轨迹不编一个“3公里100米”。不加定都阁、天坑、孔雀庵，不绕锁门、不穿工地，不从潭柘寺后山进入寺内。

## 条件落实后的一天

| 时间 | 安排 |
|---|---|
| 08:00-09:30 | 市区西部自驾预算，停车听村内管理 |
| 09:30-10:00 | 核路线、开放与撤返，先解决厕所 |
| 10:00-11:30 | 正规步道慢走、看树；11:00进度不明就返 |
| 11:30-12:30 | 沿原路回村，按最慢孩子调整 |
| 12:30-13:30 | 自带主食或事先确认的村内正规餐馆 |
| 13:30-14:00 | 村内合法道路慢走、自然笔记 |
| 14:00-15:30 | 返程；拥堵另计 |

**交通与停车：**末段公交班次未核，多孩队不优先；不照抄“路边免费停车”，满位服从管理，不依赖山路临时叫车。

**午饭与设施：**林荫小院咖啡未核主食、营业和座位，不能当正餐保障。带可直接食用的主食、温水；山路按无厕所补给准备。若订餐先问儿童不辣主食与多人座位。一家自带午饭40-80元为预算，交通另计；未核收费方式，不承诺免费。

**古树与天气：**[2021北京晚报考证转载](https://www.visitbeijing.com.cn/article/47QkJW3Z75r)对1300年树龄有不同意见，未取得最新古树档案，统一称古银杏。不食果、不摸果肉。雨后、大风、封控即取消，不侧绕进院。

结论：熟路朋友近期带路、短线轨迹和合法开放都落实后，可以重新评分；完整环穿不作这次孩子团确定方案。
