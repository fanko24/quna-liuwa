# 潭柘寺古银杏慢游

> 适用人群：8—9岁小学生与陪同成人。资料核验日期：2026-10-26。
> 2026-10-31—11-01的天气和活动仅是当次快照，不代表未来周末。路线、门票、开放及防火管控每次出发前重新确认。本文未经实地踩线，不作为GPS导航轨迹。


### 秋色判断：今年新实况比往年攻略更重要

[门头沟官方发布10月25日报道](https://xinwen.bjd.com.cn/content/s6addcdedd5def922be1bbbd4.html?innerId=1)确认：2026银杏节10月24日启幕，帝王树、配王树**向阳一侧开始变黄**。这比“往年10月底全黄”的说法可靠。

所以10月31日—11月1日值得关注，但**不能承诺满树金黄或满地金毯**；降温和风会影响转色、落叶。周五优先看景区当周照片，不用节庆海报或跨年美图当实况。

### 路线与节奏

正规入口 → 天王殿/大雄宝殿所在开放中轴 → 帝王树、配王树周边 → 允许通行的庭院、古建观察 → 原出口。

- 全程控制2—3公里、2—3小时，不连接广慧寺、定都阁、孔雀庵或天坑。
- 只在开放区域走，不保证所有殿堂、楼阁均能入内；不为拍照攀树、进围栏、坐文物构件。
- 拾叶只限允许范围的自然落叶；不碰、不吃银杏果，不摘果实。
- 热点树下不长时间占路拍照，队伍分成家长带领的小组通过，不堵台阶。
- [北京旅游网景区介绍](https://s.visitbeijing.com.cn/attraction/117841)列参考成人票50元、8:30—16:30、电话**010-60862505/60861699**；旧优惠说明只列部分人群，不能由此推断小学生政策。正式渠道核准儿童票，带证件。
- 自驾约70—100分钟估计，银杏节周末应额外预留停车排队；公共交通等候不确定，拼车更适合此次多孩团。
- 08:00北京市区西部出发 → 09:30左右入寺 → 09:30—12:00慢游 → 12:00午饭/休息 → 13:30左右返程。别把寺内2小时游览加成寺外5小时环穿。
- 入口先找厕所，景区内餐饮可作备选但不承诺座位和出餐。大风、雨雪按统一取消规则处理。

**适合：本次优先古银杏照片、文化与轻步行，而不是“运动量必须够”。**
