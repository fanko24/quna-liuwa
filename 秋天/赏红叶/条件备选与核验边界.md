# 条件备选与核验边界

> 适用人群：8—9岁小学生与陪同成人。资料核验日期：2026-10-26。
> 2026-10-31—11-01的天气和活动仅是当次快照，不代表未来周末。路线、门票、开放及防火管控每次出发前重新确认。本文未经实地踩线，不作为GPS导航轨迹。

## 对朋友推荐的两个山野方向，怎么改才能适合孩子

### 9.1 冯村—定都阁：离城近，但“近”不等于爬升低

朋友熟悉这里，推荐有参考价值；问题是“冯村出发”和“车开到较高停车点再走”不是同一种强度。

[区文旅局旧介绍](https://www.bjmtg.gov.cn/bjmtg/zjmtg/lyxx/201812/1003150.shtml)列定都峰海拔680米、东线3公里、西线4.5公里、行车道3.5公里。**这些是景区线路长度，不可拿来当冯村起步的总往返距离；海拔680米也不是实际爬升。**

更关键的是，[2026年9月18日官方公告](https://www.bjmtg.gov.cn/bjmtg/zwxx/zwgg/202609/d530bf90933445d2b5fda12dcd6b40e8.shtml)因服务与游览设施未达标准，取消定都阁AAA等级。**取消等级不等于发布闭园令，也不能反推可正常入阁。** 本次未取得更新的开放、登阁与设施核验。

因此本次不排首选。若坚持这个方向，先请熟路朋友给：
- 精确起终点和同一条近期轨迹，不能只给“冯村—定都阁”五个字；
- 实际总长、累计爬升、单段陡坡、临崖与碎石位置；
- 本周合法入口、封控与门票/登阁情况；
- 中途最短撤返点及停车接送安排。

本次孩子团可先按**总长不超过约5公里、爬升尽量不超过约300米**作为选线偏好（不是8—9岁统一能力上限）。轨迹不满足、或者开放不清楚，就换千灵山亲子线。不拿“朋友走得快”当孩子用时。

### 9.2 广慧寺—潭柘寺：改为短程往返，别直接接完整环线

[北京旅游网2026年10月18日推荐](https://www.visitbeijing.com.cn/article/4TeunGHpU29)确实提到桑峪村广慧寺和万桑古道，说明方向值得研究。它**没有提供熟路向导那条环线的精准总长、爬升、岔口、撤返和全线当前开放证明**，不能只因文字写“轻徒步”就认为适合孩子团。

本次不照搬包含天坑、孔雀庵、定都阁的完整环穿，也不把“从寺边经过”理解为穿越路线必然进入潭柘寺景区。不同同名轨迹可能很不一样，寺院门票、进出边界和村道封控要分开核实。

更适合的改法：

**潭柘寺镇桑峪村合法停车点 → 当日允许开放的正规上山步道 → 广慧寺/附近古树区域 → 原路返回同一停车点。**

这是待核的路线结构，**目前不能给它一个假的“全长3公里、爬升100米”**。须由熟路朋友近期带路或提供轨迹，并确认：
- 是潭柘寺镇桑峪村，不是斋堂附近同名桑峪村；
- 寺院及连接步道开放，不走农家地、私路或封控林地；
- 缺少清晰路牌、遇到围挡就停止，不因“导航还有一条小路”继续；
- 符合前述约5公里以内、尽量约300米以内的本次组队偏好；
- 不把找不到寺门变成临场探路，不同时安排潭柘寺寺内完整参观。

**关于“千年银杏”：** 2026旅游推荐使用“千年”表述，但[北京旅游网转载的2021年北京晚报考证](https://www.visitbeijing.com.cn/article/47QkJW3Z75r)对树龄提出不同说法。没有查到可最终消除争议的最新古树普查数据，所以对孩子可称“古银杏”，不要把精确树龄当已证实知识。若明确要看有官方长期介绍的千年古银杏，直接选潭柘寺更稳妥。

**结论：广慧寺方向可以保留，但在补齐具体路线和开放前不发成孩子团确定行程。**
