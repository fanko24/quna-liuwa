# 赏秋轻徒步：出行准备与安全

> 适用人群：8—9岁小学生与陪同成人。资料核验日期：2026-10-26。
> 2026-10-31—11-01的天气和活动仅是当次快照，不代表未来周末。路线、门票、开放及防火管控每次出发前重新确认。本文未经实地踩线，不作为GPS导航轨迹。

### 本次队伍采用的保守出行规则

以下是组织建议，不是景区统一法定门槛：

- 涉及当地的大风、雨雪、地质灾害预警，或景区闭园/路线封控：取消山地徒步，不找旁门上山。
- 山区预报阵风达到6级及以上，或现场风吹得孩子站不稳、枯枝明显摇摆：取消山路，转室内；不是换到寺院古树下继续逛。
- 山路湿滑、霜冻、结冰或低能见度：不走古石板、山脊、临崖与落叶掩盖的土路。
- 出发前查看[北京空气质量官方平台](https://zx.bjmemc.com.cn/)。本次网页只返回旧模板和空值，**未取得周末有效空气预报，不填“优”**；建议AQI超过100就不组织这次持续登山活动，敏感孩子遵循家长/医生既有要求。
- 不晚于13:30结束主要徒步，最迟15:00离开山区游览动线；这是一项宽裕的组织约束，不是景区关门时间。
- **11月1日起进入北京森林防火期，不等于所有景区一律关闭。** 但临时卡口、登记、封控必须服从，10月31日也不能野炊、烧烤或吸烟。[北京市园林绿化局说明](https://yllhj.beijing.gov.cn/ztxx/sdslfh/kpzs/202411/t20241111_3938687.shtml)
## 多个孩子一起走，组织方式比路线名更重要

### 人员与行进

- 建议至少2名成人分别领队和收队；理想约1名成人照顾1—2名孩子。这是本次组织建议，不是法定配比。
- 每个孩子固定对应监护成人；领队知道孩子姓名、紧急联系人及家长告知的过敏/用药注意事项，信息仅在必要成人间保管。
- 最快孩子不得超过领队，最后孩子后面始终有收队。岔路、厕所、车上下、进出园均按名单点数。
- 不拆成“跑得快的先登顶、慢的随便跟”；需要分组撤返时，每组都有成人、通信和明确汇合点，不能留孩子等大人。
- 不比速度，不在下坡追逐，不把一次跑5公里能力等同于连续爬升和下山能力。
- 每30—40分钟短休；有头晕、明显不适、疼痛或异常疲劳，停止前进并安排撤返/求助，不靠糖果哄着继续。

### 建议携带

每个孩子：抓地运动鞋、速干内层＋保暖中层＋防风外层，备用干衣、薄帽/手套、轻背包、本人证件/学生证明；成人分担重量。

食水：按天气与个人习惯备足饮水，孩子可先以约1—1.5升做装包参考、成人另备余量，分次饮用、不强灌；准备能实际当午餐的冷食，不只糖和薯片。所有食品垃圾带走，不喂野生动物。

公共装备：离线导览/地图、充满电手机、充电宝、头灯应急备用、基础急救包、垃圾袋、纸巾。头灯不是批准夜行的理由。登山杖不是必须，不让孩子拿杖嬉闹或戳人。

拼车：每名孩子有合法座位，使用适合身高体重的儿童约束装置/增高座椅并按车辆与产品规范使用；孩子不要仅因为“上小学了”就忽略安全带适配。

### 不安排的“山上活动”

不在斜坡上踢球、飞盘、追逐捉人、接力冲刺、蒙眼游戏；不在古树下、崖边、窄桥、寺院门口做团体竞赛。到安全平坦、园方允许且不挡通行的场地后，可以做低强度落叶配色、观察记录或合作拍照，累了直接休息。
## 出发前闭环清单：周五晚＋当天早晨

### 周五晚（10月30日）

- [ ] 选周六还是周日：看丰台/门头沟/海淀对应山区天气、风力、雨雪，不只看西城区。
- [ ] 核对景区官方新公告、指定路线是否开放，特别是11月1日防火期要求。
- [ ] 逐个问孩子近期身体状态和步行经验；有明显不适不参加。
- [ ] 确认成人、车辆、儿童座位、集合点和收队责任。
- [ ] 确认成人票、儿童票、证件、是否需预约；按正式分龄及身高规则核对优惠。
- [ ] 提前确认入口厕所和近期停车位置；沿途无补给也能完成。
- [ ] 保存正确入口与导览图，发群里明确“不登顶、不走野路、不加临时环线”。
- [ ] 设统一取消口径，避免一辆车临时改去另一条陌生野路。

### 当天出发前

- [ ] 再查气象预警、AQI、景区临时公告；有红线直接取消。
- [ ] 食水、保暖、干衣、手机电量齐备；寒冷晨间不让孩子只穿一层薄衣。
- [ ] 家长在群内报到，路线和预计结束时间留给未同行家人。
- [ ] 入园先问工作人员“今天亲子线是否完整开放？有没有临时陡阶/绕行？最近撤返点在哪？”
- [ ] 不接受仅以“大家都从这儿走”解释的封闭入口或无标志路径。
