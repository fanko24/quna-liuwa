# 水峪嘴京西古道短程往返

> 适用人群：8—9岁小学生与陪同成人。资料核验日期：2026-10-26。
> 2026-10-31—11-01的天气和活动仅是当次快照，不代表未来周末。路线、门票、开放及防火管控每次出发前重新确认。本文未经实地踩线，不作为GPS导航轨迹。


### 先消除名字歧义

“京西古道”是一张古道网络，不是一条统一难度的路线。这里选的是**妙峰山镇水峪嘴村的京西古道风景区/牛角岭方向**，不是圈门—峰口庵长穿越，也不是冯村—万桑古道。

[门头沟区文旅局2026年8月介绍](https://www.bjmtg.gov.cn/bjmtg/c104898/202507/b022fe0f4f034d6bb97f45a49a3dd213.shtml)确认景区位置、牛角岭及当地保存古道，水峪嘴村域内古道约1500米。**这1500米不是停车场到关城的精确单程距离。**

### 路线

景区正式入口/博物馆区域 → 正规游览步道 → 马蹄窝与牛角岭关城方向 → 原路回景区入口。

- 目标全程约3—4公里（含入口区域步行）、2.5—3小时；未取得实测轨迹，不声称固定爬升值。
- 先向工作人员确认当日到关城的往返长度和陡阶。如果走到单程约1.5公里/60—75分钟仍未到关城，直接折返，不以“必须看到关城”逼孩子继续。
- 石板可能磨光、凹凸多；有雨霜就不走，不让孩子在马蹄窝之间跳跃比赛。
- 不翻越关城继续穿到其他村，不临时加九龙山或峰口庵。
- 博物馆只在现场确认开放时参观，不把有馆舍当成当天一定开馆。

### 行程

08:00北京市区西部出发 → 09:20—09:40抵达、厕所和问路 → 09:45—11:00古道上行、寻找蹄窝 → 11:00—12:15原路返回 → 12:30午餐 → 13:30返程，约15:00—16:00到北京市区西部。

### 票务和补给

- [2026年区文旅局指南](https://www.bjmtg.gov.cn/bjmtg/c104897/202504/347022b6ab684c4c9f9e81b204153506.shtml)列参考票价27元、电话**010-61880498/61880104**。儿童政策、开园时刻、当日可通行范围仍需官方确认；一大一小门票先按两张全价54元做预算，不声称孩子必须全价。
- 通过景区正式渠道/窗口确认购票，不把已经结束的徒步大会报名费当门票。
- 官方8月徒步活动曾设置5公里亲子组，说明这里有家庭活动基础；**活动已结束，当时医疗点、补给站、志愿者不等于本周仍有**。
- 拼车约65—95分钟，导航“京西古道风景区（水峪嘴村）”，别只搜“京西古道”。
- 厕所、餐饮先在景区入口核对；不依赖途中小卖部。公开资料的公交站点、过桥路线未作本周运营验证，多孩队不临时摸索步行过桥接驳。
- 秋色可能有林间彩叶，但没有取得近两日全线叶色实拍，**不承诺红叶密度超过西山**。

### 给孩子的任务

“这些坑一定是马踩的吗？为什么集中在石路上？”“关隘为什么建在这里？”“古时候运煤、运货为什么不用车？”先观察再讲故事，不把文学传说当历史定论。
