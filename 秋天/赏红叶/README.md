# 北京赏红叶与古银杏：方案比较

> 适用人群：8—9岁小学生与陪同成人。资料核验日期：2026-10-26。
> 2026-10-31—11-01的天气和活动仅是当次快照，不代表未来周末。路线、门票、开放及防火管控每次出发前重新确认。本文未经实地踩线，不作为GPS导航轨迹。

## 怎么选

- 想让孩子真正爬一点山：首选[千灵山官方3.7公里亲子线](01-千灵山亲子线.md)，不登主峰。
- 想更近、重点看红叶：选[西山低位赏红短线](02-西山低位赏红.md)。
- 想边走边找历史线索：选[京西古道短程往返](03-京西古道短线.md)。
- 队伍体力差异大：选[戒台寺](04-戒台寺慢游.md)或[潭柘寺](05-潭柘寺银杏.md)寺内慢游。
- 想走定都阁、广慧寺环线：先看[条件备选与核验边界](条件备选与核验边界.md)，不要直接复制成人环穿。

## 候选总表：按本次孩子团的综合适合程度排序

“步行控制目标”是本方案给队伍设定的量，不是冒充实测路线。**官方3.7公里以外，没有可靠轨迹支撑的路线不编造累计爬升。山顶海拔也不等于累计爬升。**

| 本次不优先 | 冯村—定都阁；广慧寺—潭柘寺完整环线 | 起点/分支不同，强度可能差很多 | 山顶视野、古道秋色 | 缺本轮开放/轨迹核验，多孩队不临场探路 | 通勤近不代表山路容易 |

**如何快速选：**
- 想让孩子真正“爬一点山”：千灵山3.7公里亲子线。
- 车程和红叶优先：西山低位短线。
- 孩子喜欢探险故事而非一直看风景：京西古道。
- 有第一次走山路、最近生病或耐力不明的孩子：戒台寺或潭柘寺。
- 若只能公共交通且不想打车：优先重新核对西山东门的当日接驳，不优先组织桑峪村环穿。不要把“有公交”理解成“适合一群孩子折腾一整天”。

## 为什么没把香山、坡峰岭、灵山等再塞进来

- **香山、八大处：** 成熟、近，但本次是多人小学生队伍，赏叶高峰的人流与队伍管理成本高。若选也应走低位，不追顶。
- **坡峰岭：** 赏红强，但热门窄路、人流和更长车程会抵消优势；不比千灵山3.7公里线更适合这次的“低难度组队”目标。
- **灵山、百花山高处：** 海拔、风寒、路况和车程不匹配此次轻徒步目标，不建议为“秋色”升级到高海拔。
- **北宫国家森林公园：** 10/17—11/15彩叶季有官方旅游平台介绍，可作为后续替换；本轮未进一步核实具体低难度闭合线路与运营字段，不为凑候选额外做一份看似可直接导航的计划。

[平安北京10月20日提示](https://www.bjswzfw.gov.cn/zz1/ggaq/202610/t20261020_1682200.html)明确预计10月31日、11月1日是彩叶客流高峰。因此对所有地点都不保证“人少”，早点进、午后返只是降低拥挤风险的组织策略。

## 先看安全，再定日期

出发前必须读[出行准备与安全](出行准备与安全.md)。本主题以2026年10月底的一次研究为起点，不能把当时的天气和银杏转色结论用于其他日期。

交通按自驾或家长拼车提供估计；不包含实时导航、停车预约或公交班次保证。文中“北京市区西部出发”是泛化的出发条件，实际交通以各家庭为准。
