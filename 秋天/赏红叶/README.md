# 北京赏红叶与银杏：8个亲子一日选择

> 20261026-v2｜北京西城、海淀、朝阳等各城区分别出发｜8-9岁小队｜自驾或公共交通当天往返｜参考强度约7公里、爬升300米，可安排完整一天。千灵山和不再推荐的独立旧页已移除。

## 集合与返程

各家庭从西城、海淀、朝阳等实际地址分别出发，在景区入口集合，不先绕到一个市区点。出门时刻=集合时刻-本家当日路线预计耗时-停车/步行20至30分钟。各方案的分钟数只是跨城排程宽预算，不是导航实测；不能把行政区当成一个固定起点。

普通线路约14:30至15:30点名解散，广慧寺两寺一阁约15:45至16:00结束；各家按实际交通回城，不承诺相同到家时间。10月底日落约17:13，山谷会更早暗，山路以16:00前结束为目标。公交家庭必须在周五核去返班次、末班和末段接驳，不能靠下山临时叫车。
